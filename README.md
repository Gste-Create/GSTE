# GSTE — Guitar Score Transcription Engine

**GSTE Beta V0.1** 是一套輸入 MusicXML 樂譜，自動轉換成可演奏的 **指彈吉他（fingerstyle guitar）TAB** 的桌面軟體。

**GSTE Beta V0.1** is a desktop application that takes MusicXML scores as input and automatically converts them into playable **fingerstyle guitar TAB**.

---

## Beta V0.1 支援 / Current Beta Scope

- **雙手鋼琴模式**：輸入鋼琴雙手 MusicXML，分析主旋律、Bass、和聲與伴奏，重新編排為指彈吉他 TAB。
- **單旋律模式**：輸入單一主旋律 MusicXML，保留原始旋律並自動分析和聲、產生伴奏。
- 依照吉他的演奏限制進行指彈編曲與指法配置。
- 輸出 MusicXML / TAB。
- 所有樂譜轉換皆於本機執行。
- 團譜功能目前尚未開放。

**English**

- **Piano mode:** Takes a two-hand piano MusicXML score, analyzes its melody, bass, harmony, and accompaniment, and rearranges it into fingerstyle guitar TAB.
- **Melody mode:** Takes a single-melody MusicXML score, preserves the original melody, and automatically analyzes the harmony and generates accompaniment.
- Arranges the music and assigns fingering according to guitar playability constraints.
- Outputs MusicXML / TAB.
- Score conversion is performed locally on the user's computer.
- Ensemble-score input is not currently available.

## AI 協作 / AI Collaboration

GSTE 的正常轉換流程在本機執行，**不依賴 AI**。AI 可能用於專案開發、程式 review、除錯、測試與文件協作，但版本與發布內容由人類審查。提交樂譜進行問題回報不代表自動同意 AI 分析。詳見 [`AI_POLICY.md`](AI_POLICY.md)。

Normal GSTE conversion runs locally and **does not depend on AI**. AI may assist development, code review, debugging, testing, and documentation, while release decisions remain human-reviewed. Submitting a score for issue reporting does not automatically authorize AI analysis. See [`AI_POLICY.md`](AI_POLICY.md).

## Beta 注意事項 / Beta Notice

本版本仍屬測試版本。

產生的編曲可能存在音樂性、節奏、和聲、指法、排版或轉換問題。演奏、公開或再散布前，請人工確認輸出結果。

**English**

This is a Beta release and is still under testing.

Generated arrangements may contain issues related to musical quality, rhythm, harmony, fingering, notation, or conversion. Please review the output manually before performing, publishing, or redistributing it.

## 隱私安全錯誤回報 / Privacy-Safe Issue Reporting

Beta 會產生 `PRIVACY_SAFE_DEBUG_REPORT.md` 作為預設問題回報檔案。它採白名單方式保留工程診斷資訊，並刻意排除直接樂譜內容與來源識別欄位。完整工程診斷仍保留在本機 `debug/`，不建議在保密或商業專案中直接分享。詳見 [`PRIVACY.md`](PRIVACY.md) 與 [`docs/user/ISSUE_REPORT_GUIDE.md`](docs/user/ISSUE_REPORT_GUIDE.md)。

**English**

Beta generates `PRIVACY_SAFE_DEBUG_REPORT.md` as the default file for issue reporting. It uses an explicit allow-list of engineering diagnostics while excluding direct score-content and source-identifying fields. Full engineering diagnostics remain local under `debug/` and should not be shared by default for confidential or commercial projects.

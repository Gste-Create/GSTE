# GSTE Beta V0.1 — Release Notes / 發布說明

## 中文
GSTE Beta V0.1 是 Guitar Score Transcription Engine 的第一個公開驗證版本。

**公開下載：** `GSTE_Beta_V0.1_Setup.exe`（Windows 安裝版；一般使用者不需另裝 Python）。

**目前包含：** Piano 與 Melody MusicXML 轉換、指彈吉他 TAB / MusicXML 輸出、繁中 / English GUI、轉換與錯誤報告、`PRIVACY_SAFE_DEBUG_REPORT.md`。團譜輸入目前不開放。

正常轉換在本機執行，不依賴 AI。專案開發與除錯可能使用 AI 協作，詳細界線請見 `AI_POLICY.md`。

Beta 成功轉換代表流程完成並產生輸出，不代表每個音樂、和聲、節奏、指法或排版決策都正確。演奏、公開或再散布前請人工確認。

本 repository 另提供 5 首 Melody + 5 首 Piano 的公開 Demo 輸入與對應 GSTE 最終 TAB，供功能展示與測試。來源與權利紀錄見 `demo/RIGHTS_AND_SOURCES.md`。

## English
GSTE Beta V0.1 is the first public validation release of the Guitar Score Transcription Engine.

**Public download:** `GSTE_Beta_V0.1_Setup.exe` (Windows installer; users do not need a separate Python installation).

**Included:** Piano and Melody MusicXML conversion, fingerstyle guitar TAB / MusicXML output, Traditional Chinese / English GUI, conversion/error reports, and `PRIVACY_SAFE_DEBUG_REPORT.md`. Ensemble-score input is not currently available.

Normal conversion runs locally and does not depend on AI. AI may assist project development and debugging; see `AI_POLICY.md` for the boundary.

A successful Beta conversion means the workflow completed and generated output; it does not guarantee that every musical, harmonic, rhythmic, fingering, or notation decision is correct. Review results before performance, publication, or redistribution.

The repository also provides five Melody and five Piano public demo inputs with corresponding final GSTE TAB outputs for demonstration and testing. See `demo/RIGHTS_AND_SOURCES.md` for provenance and rights records.

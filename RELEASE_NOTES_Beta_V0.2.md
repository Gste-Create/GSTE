# GSTE Beta V0.2 發布說明

[繁體中文](#繁體中文) · [English](#english)

## 繁體中文
本說明依本次 GSTE_Beta_V0.2_Setup.exe 與 Portable 包的靜態檢查整理，未執行 Windows GUI。

- 視窗名稱常數為 GSTE Beta V0.2；內部 VERSION 仍為 group_V0.1，部分團譜提示仍寫 Beta V0.1。這是程式文字尚未統一，文件無法修改 EXE。
- GUI 文字確認有雙手鋼琴與主旋律模式，主旋律可選自動伴奏或不加伴奏。
- 團譜為保留入口，GUI 明示尚未開放。內部存在 ensemble 模組不代表公開可使用。
- 未確認可供使用者操作的 MIDI 輸入；不得以內部 midi 音高欄位或模組名稱宣稱已支援 MIDI。
- 不以本次二進位靜態檢查宣稱轉換品質、延音問題或其他 bug 已完全修復。

本次文件更新：版本名稱、授權索引、隱私與回報說明、安裝及 Portable 使用方法、安全檢查範圍。

2026-10-03 雙語修訂：補齊中文與英文公開文件、統一使用指南為 Beta V0.2、更新文件校驗碼；未重建二進位或重新產生 Demo 音符。

## English

These release notes preserve the recorded static inspection of GSTE_Beta_V0.2_Setup.exe and the Portable package. The Windows GUI was not executed in that inspection.

- The window-name constant is GSTE Beta V0.2. The internal VERSION remains group_V0.1, and some group-score prompts still say Beta V0.1. These are inconsistent program strings; documentation cannot change the EXE.
- GUI strings identify two-hand Piano and Melody modes. Melody supports automatic accompaniment or conversion without accompaniment.
- Group-score mode is a reserved entry explicitly marked unavailable in the GUI. Internal ensemble modules do not make it a public feature.
- No user-operable MIDI input was confirmed. Internal midi pitch fields or module names are not evidence of public MIDI support.
- The static inspection does not establish that conversion quality, tie issues or other bugs are fully fixed.

The document update covers version naming, licensing references, privacy and reporting, installation / Portable use, and the scope of security review. The 2026-10-03 bilingual revision adds complete Chinese and English public documentation, aligns user-guide headings with Beta V0.2, and updates document checksums. It does not rebuild the binaries or regenerate demo notes.

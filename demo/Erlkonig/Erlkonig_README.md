# Erlkönig（魔王）— GSTE V0.4 Beta 轉換展示

## 1. 作品與展示概要

- **原作**：Franz Schubert — *Erlkönig*, D. 328
- **輸入樂譜**：聲樂與鋼琴版（Piano & Voice）
- **來源**：[MuseScore — jojo288](https://musescore.com/jojo288/erlk-ning)
- **來源樂譜授權**：CC BY 4.0
- **轉換工具**：GSTE V0.4 Beta
- **轉換小節**:第 57–148 小節。
- **輸出**：指彈吉他五線譜與 TAB 草稿

本展示測試將人聲主旋律與鋼琴伴奏整合為單把吉他的編曲流程。來源署名、改編範圍及再利用條件詳見 `Erlkonig_ATTRIBUTION.md`。

## 2. 轉換流程

### 人工前處理

- 保留大部分原始主旋律，僅將第 30–40 小節主旋律提高八度。
- 精簡鋼琴右手伴奏，將部分重要伴奏音符合併至 Melody：第 1–15 小節三連音、第 31–39 小節伴奏、第 57–59 與 76 小節低音、第 84–86 小節右手伴奏，以及結尾右手和弦。
- 將鋼琴左右手聲部整理為單一主要伴奏音軌（Guitar）：大部分採用右手聲部，移除已併入 Melody 的第 1–15、31–39 小節伴奏；第 16–24 小節合併左右手，第 78–84 小節改採左手伴奏。

### GSTE 自動轉換

依 Melody 與 Guitar 的角色設定進行吉他編曲與指法配置，輸出五線譜及 TAB。

### 人工後處理

- 檢查輸出音符、指法與伴奏配置。
- 將第 31–39 小節分解和弦獨立轉換後，再合併至 TAB。目前選擇保留最多伴奏音符的編排方式，實際演奏時需在伴奏保留度與指法流暢性做取捨。
- 刪除第 59 小節不需要的高音音符。

> 上述操作小節編號為本次展示之TAB譜編號，非對應原譜段落。

## 3. 轉換觀察與限制

- **樂譜排版問題**:GSTE 輸出的 MusicXML 匯入 MuseScore 4 後，部分小節可能因多聲部休止符同時顯示，造成五線譜與 TAB 排版擁擠，影響閱讀。
    此問題主要涉及譜面顯示，不一定影響實際音符、指法或播放結果。目前尚未全面優化休止符排版，建議以 TAB 指法及實際播放結果作為輔助參考。
- **伴奏整合策略**：本次測試發現，三拍子伴奏預先併入 Melody 時保留效果較佳；第 31–39 小節分解和弦則適合獨立轉換後再合併。此為個案觀察，尚未形成通用規則。
- **旋律與伴奏競爭**：當伴奏音符預先併入 Melody，主旋律骨架分析可能將部分音符判為次要旋律；團譜轉換時加入其他伴奏，也可能降低這些音符的保留機會。
- **播放異常**：部分位置的五線譜休止符可能伴隨 TAB 未顯示的額外聲音。展示時可暫時停用 Guitar Standard 聲部、僅播放 Guitar TAB，並檢查伴奏音量；根因仍待確認。

## 4. 回饋方向

歡迎針對三連音與分解和弦的保留方式、主旋律清晰度、指法合理性，以及實際演奏的流暢度提出建議。

# GSTE V0.3 — Demo

本包包含六個 V0.3 實際轉換案例：四個主旋律、一個鋼琴、一個團譜。

This package contains six actual V0.3 conversion cases: four melody, one piano and one ensemble.

各案例的 `input/` 保存輸入，最終樂譜見下表，來源授權見 `SOURCE_LICENSE.md`。轉換結果的音符及指法未經人工修改，仍需播放與演奏核對。主旋律與雙手鋼琴的《給愛麗絲》是不同輸入模式的兩個案例。

Inputs are retained in each case's `input/` folder. Final scores and source licenses are linked below. Converted notes and fingerings have not been manually edited; playback and performance review remain necessary. The melody and piano versions of Für Elise are separate input-mode cases.

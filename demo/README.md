## 檔案用途

- input/：實際轉換輸入。鋼琴採 RH/LH 分開輸入。
- source/ 或 original：上游素材與完整譜參考。Mutopia 曲目保留 MIDI、LilyPond 與其權利欄位。
- GSTE_TAB.musicxml：GSTE 轉換結果。
- CONVERSION_REPORT.md：原始摘要，保留 group_V0.1 實際引擎標記。本次未重新轉換。
- SOURCE_LICENSE.md：每首來源、權利與署名說明。
- DEMO_LICENSE_INDEX.json：本版唯一的權利判定索引；DEMO_LICENSE_INDEX.md 是可讀摘要。
- INPUT_SOURCE_MAP.json：公開檔案與轉換輸入配對。
- SHA256SUMS.txt：本資料夾檔案校驗碼。

## 音樂權利

Mutopia 素材依各曲目原始 Public Domain 聲明提供；給愛麗絲採 OpenScore CC0 版本。上游的公版／CC0 聲明在 GSTE 轉換後仍需保留；本次未另行變更維護者新增編排／指法的權利。GSTE Beta 軟體條款不替這些音樂素材增加限制。保留作曲家與上游製譜者資訊，引用時請清楚標記 GSTE-generated output，不暗示原作者背書。

來源核對基於網站公開聲明、檔內權利欄位與附件來源鏈，並非法律認證。成功代表完成轉換，音樂性、可演奏性及閱讀器顯示仍需人工確認。

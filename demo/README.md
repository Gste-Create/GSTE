# GSTE Public Demo / 公開示範資料

## 中文
本資料夾提供 GSTE Beta V0.1 公開展示與測試用的 **5 首單旋律 + 5 首鋼琴**資料。每個曲目資料夾同時保留公開 Demo 輸入與 GSTE Beta V0.1 產生的最終 TAB MusicXML。

- `melody/`：`input_melody.musicxml` + `<資料夾名稱>_GSTE_Beta_V0.1_TAB.musicxml`
- `piano/`：`input_RH.musicxml`、`input_LH.musicxml`、核對用 `original_source.mxl` + `<資料夾名稱>_GSTE_Beta_V0.1_TAB.musicxml`
- `RIGHTS_AND_SOURCES.md`：逐曲來源、權利狀態與處理方式
- `SHA256SUMS.txt`：本凍結 Demo 包的檔案完整性校驗值

鋼琴路徑實際輸入為 RH/LH 兩份 MusicXML；`original_source.mxl` 僅供拆分前後核對。輸出的 TAB 是 **GSTE 產生的指彈吉他編曲結果**，不是原作曲家的原始吉他編曲。Beta 輸出仍應人工檢查。

資料來源依來源網站標示為 CC0 或 Public Domain；兩種權利類別保持原標示，不互相替代。公開再散布 Demo 時請保留本檔與 `RIGHTS_AND_SOURCES.md`。

## English
This directory provides **5 Melody + 5 Piano** public examples for GSTE Beta V0.1 demonstration and testing. Each work directory contains the public demo input together with the final TAB MusicXML generated by GSTE Beta V0.1.

- `melody/`: `input_melody.musicxml` + `<folder-name>_GSTE_Beta_V0.1_TAB.musicxml`
- `piano/`: `input_RH.musicxml`, `input_LH.musicxml`, audit-only `original_source.mxl` + `<folder-name>_GSTE_Beta_V0.1_TAB.musicxml`
- `RIGHTS_AND_SOURCES.md`: per-work provenance, rights status, and processing notes
- `SHA256SUMS.txt`: integrity hashes for this frozen demo package

The Piano workflow uses the RH/LH MusicXML files; `original_source.mxl` is retained only for source-to-split verification. The TAB files are **fingerstyle guitar arrangements generated by GSTE**, not original guitar arrangements by the composers. Beta output should still be reviewed by a human.

Sources are recorded according to their published CC0 or Public Domain statements; those rights classes are not relabelled as one another. Keep this README and `RIGHTS_AND_SOURCES.md` with public redistribution of the demo set.

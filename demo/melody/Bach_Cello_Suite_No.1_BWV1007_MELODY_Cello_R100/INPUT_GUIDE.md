# Demo 輸入說明 / Input Guide

Melody 模式使用 [input/input_melody.musicxml](input/input_melody.musicxml)。本例為 V0.3 主旋律轉換結果；各模式細節以原轉換報告記錄為準，不從檔名推測 Auto／None。

Use the supplied melody input. The final score is the actual supplied V0.3 result; accompaniment mode is not inferred from filenames.

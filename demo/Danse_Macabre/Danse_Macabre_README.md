# Danse macabre — GSTE V0.4 Beta 轉換展示

## 1. 作品與展示概要

- **原作**：Camille Saint-Saëns — *Danse macabre*, Op. 40
- **輸入樂譜**：小提琴與鋼琴編曲版（MusicXML）
- **來源**：[Classical Music Index — Score #616759](https://www.classicalmusicindex.org/item.php?id=9369&type=11)
- **來源樂譜授權**：CC BY-SA 4.0
- **轉換工具**：GSTE V0.4 Beta
- **轉換小節**:第 26–85 小節，於第 85 小節第一個音符後結束。
- **輸出**：指彈吉他五線譜與 TAB 草稿

本展示透過人工前處理、GSTE 自動編曲及人工後處理，探索多樂器樂譜轉換為指彈吉他譜的可行性。來源署名、改編範圍及再利用條件詳見 `Danse_Macabre_ATTRIBUTION.md`。

## 2. 轉換流程

### 人工前處理 (Prepared)

1. 主旋律音軌 (Melody)
- 整理主旋律，將音域偏低且容易與伴奏衝突的第 25–39 小節主旋律提高八度。
2.第一伴奏音軌（Guitar）
- 將橫跨鋼琴左右手的三拍子伴奏整理至第一伴奏音軌。
- 移除與主旋律重疊的右手伴奏片段，並複製左手的三拍子伴奏型態。
- 將低於吉他音域的第 9–16 小節右手伴奏提高八度。
3. 第二伴奏音軌（Bass）
- 保留鋼琴左手原始伴奏，配置於第二伴奏音軌。

### GSTE 自動轉換 (Raw GSTE)

依 Melody、Guitar、Bass 的角色設定進行吉他編曲與指法配置，輸出五線譜及 TAB。

### 人工後處理 (Final)

- 檢查自動輸出的音符、指法、伴奏與譜面。
- 補足第 8–11、16、17、20、22、23 小節的伴奏三連音。
- 刪除第 13、14、24 小節不需要的高音音符。

> 上述操作小節編號為本次展示之TAB譜編號，非對應原譜段落。

### 調號與等音異名記譜說明

原曲以 G 小調為主要調性，調號包含 B♭ 與 E♭。本次展示樂譜在小節裁切與重新整理後，未完整保留原始調號，因此部分音符以臨時升降記號呈現。

此外，樂譜經過 GSTE 自動轉換及 MusicXML 匯出後，部分音符採用等音異名（Enharmonic Spelling）記譜，例如將 E♭ 表示為 D♯。兩者在十二平均律下具有相同的 MIDI 音高，但在樂理與和聲功能上並不完全等同。

由於本次展示主要著重於 GSTE 的旋律保留、伴奏編排與吉他指法配置，因此暫未全面修正調號及等音異名記譜。此現象屬於樂譜記譜方式的差異，不代表樂曲經過整體移調。

後續版本將評估改善調號保留與等音異名記譜的一致性，以提升樂譜可讀性。


## 3. 轉換觀察與限制

- **伴奏保留**：本次測試約有五分之一的三拍子伴奏小節出現音符遺漏，需要人工補足。此比例為本曲觀察值，並非整體演算法統計。
- **指法配置**：目前主要考慮把位與可演奏性限制，尚未充分納入不同琴弦的音色差異。
- **編曲目標**：本版優先評估原曲旋律與伴奏的保留程度，不一定是最流暢或最適合現場演奏的吉他版本。
- **播放異常**：部分位置的五線譜休止符可能伴隨 TAB 未顯示的額外聲音。現階段展示時可暫時停用 Guitar Standard 聲部，僅播放 Guitar TAB，並檢查伴奏音量；此方式為播放端暫行處理，尚非根因修復。

## 4. 回饋方向

歡迎針對指法合理性、跨弦音色、伴奏取捨、原曲辨識度與演奏流暢度提出建議，以作為後續版本改善依據。

## English

These documents describe the public functionality, operation and reporting workflow of **GSTE Beta V0.2**. Each guide includes Traditional Chinese and full English content in the same file.

| Document | Purpose |
|---|---|
| [Installation and GUI use](user/GETTING_STARTED.md) | Windows installer, Portable, Piano / Melody / melody-only input and review. |
| [Current limitations](user/CURRENT_LIMITATIONS.md) | Supported scope, guitar constraints and known issues. |
| [Output guide](user/OUTPUT_GUIDE.md) | Scores, summaries and diagnostic files. |
| [Issue reporting](user/ISSUE_REPORT_GUIDE.md) | Minimal reports and inspection before sharing. |
| [AI sharing guide](user/AI_SHARING_GUIDE.md) | File classification for pitch, timing, statistics and sensitive text. |
| [Troubleshooting](user/TROUBLESHOOTING.md) | Launch failures, conversion issues and score-display problems. |

Public workflows focus on MusicXML Piano and Melody modes. Group scores are unavailable; MIDI has not been confirmed as a public feature. Historical internal-engine and report labels are distinct from the guide version. Updating documentation does not update the EXE.

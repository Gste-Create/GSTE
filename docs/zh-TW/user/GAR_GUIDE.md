# GAR 編曲索引 — V0.4 beta（實驗性功能）

## 功能目的
GSTE 可將 MusicXML 轉換為供使用者檢查的指彈吉他五線譜與 TAB。GAR 則提供把位、和弦指法與伴奏配置的參考建議，協助使用者依照原曲風格、聽感及演奏能力，自行判斷適合的編曲方式。

GAR 是編曲參考工具，並非 MuseScore 等樂譜編輯軟體的替代品。

## 使用方式
1. 使用 GSTE V0.4 beta 轉換 MusicXML，並檢查輸出的 `GSTE_TAB.musicxml`。
2. 開啟 GAR，選擇要查看的轉換結果：
   - **剛完成的轉換**：直接進入 GAR，查看本次轉換的樂譜。
   - **先前的轉換結果**：在 GAR 選擇先前轉換檔案中的 `GSTE_EDITOR_CONTEXT`，載入該份樂譜供查看。無須為了查看舊結果而重新轉換原譜。
3. 選取欲檢查的小節；GAR 主要顯示目前選取的小節。
4. 在 TAB 上點選主旋律音符，查看對應的雙音建議。
5. 使用整合的「和弦指法／伴奏編排索引」，查看主旋律把位附近、未佔用弦上的候選配置，以及六線 TAB 示意。
6. 根據音樂風格、實際聽感與演奏可行性評估建議。如需修改樂譜，請使用其他樂譜編輯工具完成。

## 使用限制
**GAR V0.4 beta 為唯讀編曲索引。** 在 GAR 中查看或選擇候選，不會將修改寫回 GSTE，也不會執行 Joint 編曲、重新計算或輸出修改後的樂譜。

候選內容是簡化的靜態參考，不保證所有手型均可實際演奏，也不保證其節奏完全符合原譜。使用者仍需自行檢查與調整。

## 意見回饋
歡迎分享希望保留的聲部、期待改善的編曲操作方式，或不合理的候選建議。回饋時請盡可能提供程式版本、小節位置、來源音軌數量及預期結果；不需要附上完整 Debug 資料。公開分享樂譜前，請先確認其授權條件。

# GSTE V0.3 — 輸入模式與角色

| 模式 | 必要檔案 | 伴奏方式 |
|---|---|---|
| 主旋律＋自動伴奏 | 一份主旋律 | 生成伴奏 |
| 主旋律＋無伴奏 | 一份主旋律 | 不添加伴奏 |
| 鋼琴 | 主旋律／右手與左手／伴奏 | 來源分析 |
| 團譜 | 主旋律與一至四個伴奏軌 | 角色分析與融合 |

## 團譜吉他

GUITAR 是吉他伴奏角色，可同時輸入多軌吉他。刷奏、分解和弦等型態由音樂內容分析，不由主奏或節奏吉他的名稱決定。主旋律仍須由獨立檔案提供。

重要伴奏可放在較前面的欄位。程式為各欄套用固定權重，再結合角色權重及分析信心進行融合；權重不代表音符保留百分比，也不保證整軌完整保留。來源識別會區分各軌，但融合可能刪減衝突材料。指定吉他角色不保證每次刷奏、分解和弦或華彩原樣保留。

## 鋼琴來源音政策

鋼琴預設採 `SOURCE_AT_ATTACK`：伴奏起音候選受該起音的來源音約束，同一實體小節採共同的八度位移。起音與音符可能刪減，延音可能縮短。八度選擇以音域為依據，尚非全域手型最佳化。

目前未提供每個來源伴奏起音至少保留一音的強制機制，也未提供整樂句或拍群的八度位移。不能據此宣稱團譜每軌具有相同的來源保留保證。

# GSTE V0.3 — 目前限制

- **輸入：**介面使用未壓縮 MusicXML，未提供完整 MIDI 輸入轉換支援。多軌需準備對齊的分開檔案。
- **團譜：**實驗模式最多四個吉他／貝斯伴奏欄位。多軌融合品質仍需更多曲目測試，結果可能隨伴奏配置與來源材料而異。
- **鋼琴來源材料：**來源音約束與逐小節八度位移不保證每個起音或延音完整保留，八度選擇尚非全域手型最佳化。
- **節奏與型態：**辨識不保證完整理解及保留不規則拍、切分、弱起、長週期樂句或跨分析區段的樂句。
- **調性與和聲：**關係大小調的判斷可能接近；完整的局部轉調、終止式與和聲推理尚未最佳化。
- **音樂品質：**輸出可能刪減材料，伴奏密度、手型、把位與連接仍需人工聆聽及演奏檢查。
- **語言：**介面支援中英文切換，新增外層人工檢查報告以中文為主。

轉換結果仍需以讀譜軟體播放並由人工演奏核對。

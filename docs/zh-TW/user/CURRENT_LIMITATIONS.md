# GSTE V0.4 — 目前限制

- **輸入：**介面使用未壓縮 MusicXML，未提供完整 MIDI 輸入轉換支援。多軌需準備對齊的分開檔案。
- **團譜：**實驗模式最多四個吉他／貝斯伴奏欄位，團譜鋼琴選項已隱藏。多軌融合品質仍需更多曲目測試，結果可能隨伴奏配置與來源材料而異。
- **鋼琴來源材料：**來源音約束與逐小節八度位移不保證每個起音或延音完整保留，八度選擇尚非全域手型最佳化。
- **節奏與型態：**辨識不保證完整理解及保留不規則拍、切分、弱起、長週期樂句或跨分析區段的樂句。
- **調性與和聲：**關係大小調的判斷可能接近；完整的局部轉調、終止式與和聲推理尚未最佳化。
- **音樂品質：**輸出可能刪減材料，伴奏密度、手型、把位與連接仍需人工聆聽及演奏檢查。
- **語言：**GUI 支援繁體中文、英文與日文；報告摘要可隨介面語言顯示，原始技術診斷可能仍包含英文代碼或未翻譯內容。

轉換結果仍需以讀譜軟體播放並由人工演奏核對。

## V0.4 beta／GAR 新增限制

- GAR 編曲索引目前**唯讀**，不是可直接套用指法、局部重算或完整記譜的成熟編輯器。
- 指法與伴奏模板僅供參考，未經完整 GSTE Joint 驗證；需人工檢查演奏可行性、節奏與音樂性。
- 團譜最多四個伴奏欄位，建議先從一至兩軌嘗試；兩軌也可能造成顯著音樂資訊壓縮。
- 本版沒有宣稱自動轉譜演算法、音樂性或 Demo 品質較 V0.3 全面提升。

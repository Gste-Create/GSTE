# GSTE V0.3 — 檔案分享指南

正常轉換不會自動將樂譜上傳至人工智慧服務。公開問題回報的附件也會公開。若不希望揭露音樂內容，請先提供適合分享的問題描述及白名單摘要，而非整個輸出壓縮檔。

| 檔案 | 建議 |
|---|---|
| `PRIVACY_SAFE_DEBUG_REPORT.md` | 優先提供，仍須先檢查內容。 |
| `EVENT_LIFECYCLE_TRACE.md` | 精簡生命週期資料，確認符合分享範圍後提供。 |
| `CONVERSION_REPORT.md`／`ERROR_REPORT.md` | 先檢查；錯誤可能包含路徑、位置或來源文字。 |
| `HUMAN_REVIEW_REPORT.md`／`MEASURE_LOCATION_GUIDE.md` | 包含位置與證據連結，不是隱私摘要。 |
| 原譜、最終譜、截圖、`debug/`、來源音稽核 | 可能揭露音高、節奏、和弦、來源識別及完整音樂內容。 |

提交樂譜不代表同意第三方人工智慧分析。請依[問題回報指南](ISSUE_REPORT_GUIDE.md)明確選擇；未明確同意時，維護者不得將提交的樂譜用於人工智慧輔助分析。精簡報告可協助初步定位工程問題，但未必能判斷音樂品質。

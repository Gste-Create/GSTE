# GSTE V0.3 — 常見問題

## 安裝或啟動問題

確認下載的是 GSTE V0.3 的 EXE 安裝檔，並已完成安裝。透過安裝後的捷徑啟動程式。若仍有問題，請記錄 Windows 版本、GSTE 版本、問題發生於安裝或啟動階段，以及錯誤訊息或截圖。

## 轉換失敗

檢查 `.musicxml`／`.xml` 格式、必要輸入與輸出路徑。鋼琴需兩份檔案；團譜需主旋律與至少一個伴奏。確認各軌時間軸一致；更改 `.mxl` 或 MIDI 的副檔名不會轉換格式。

閱讀 `ERROR_REPORT.md` 的原因與失敗階段。`NO_VALID_GLOBAL_TRANSFORM` 不一定表示超出音域。團譜轉換失敗時，請一併記錄所選角色、輸入檔及報告中的錯誤訊息。請保留本次報告及版本資訊以便追查。

## 成功後譜面異常

核對外層 `GSTE_TAB.musicxml`，不要只看中間樂譜。透過 `MEASURE_LOCATION_GUIDE.md` 記錄原譜小節標籤與選段序號，指出旋律、伴奏、節奏或指法的差異。讀譜軟體有問題時請提供其版本，並區分 XML 音符內容與畫面呈現問題。

缺少位置或顯示 `NOT_AVAILABLE` 代表證據不足，不代表已確認正確。詳見[問題回報指南](ISSUE_REPORT_GUIDE.md)。

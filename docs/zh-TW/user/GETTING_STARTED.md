# GSTE V0.4 beta — 安裝與操作

## 安裝與啟動

1. 從版本下載頁下載 GSTE V0.4 beta 的 EXE 安裝檔。
2. 執行下載的安裝檔，依照畫面指示完成安裝。
3. 透過安裝後的應用程式捷徑啟動 GSTE。

不需另外安裝 Python。下載的 EXE 是安裝檔，請先完成安裝再使用程式。

## 準備輸入

使用未壓縮的 `.musicxml` 或 `.xml`，先在樂譜軟體確認可以開啟。壓縮的 `.mxl` 請先另存為未壓縮 MusicXML。本版圖形介面不提供完整的 MIDI 輸入轉換支援。

鋼琴與團譜模式需準備分開的輸入檔，並確認時間起點、小節位置與拍號一致。

## 選擇模式

1. **僅主旋律：**選一份旋律檔，再選自動生成伴奏或不添加伴奏。旋律跨鋼琴左右手時，請先整理為獨立旋律輸入；不添加伴奏不代表自動辨識全部跨手旋律。
2. **雙手鋼琴：**分別選主旋律／右手與左手／伴奏檔。伴奏由來源分析；介面沒有強制保留每個伴奏起音的選項。
3. **團譜（實驗）：**選主旋律與一至四個伴奏檔。各伴奏指定 GUITAR（吉他）或 BASS（貝斯）。多軌吉他可使用同一角色，無需分成主奏與節奏吉他。較前面的伴奏欄位具有較高的固定融合權重；這不是音符保留百分比，也不保證前面的軌道逐音保留。詳見[輸入模式](INPUT_MODES.md)。

## 轉換與檢查

選擇介面語言與輸出資料夾，按「開始轉換」。每次轉換會建立結果資料夾；成功後可用「開啟完成樂譜」或「開啟輸出資料夾」。

先檢查旋律、節奏與譜面，再依人工檢查報告核對指法及伴奏。失敗時閱讀 `ERROR_REPORT.md`，詳見[輸出指南](OUTPUT_GUIDE.md)。

語言切換只改變介面文字。新增外層人工報告目前以中文為主，工程報告仍保留英文欄位名稱。

## V0.4 beta：GAR 編曲索引（實驗性）

完成 GSTE 轉換後開啟編曲索引，選擇欲檢視的小節，在整合的「和弦指法／伴奏編排」索引中查看主旋律附近、未佔用弦的候選與六線 TAB 圖像，作為目前伴奏可用弦位、和弦修改後可用弦位參考。以及主旋律雙音指法編排建議。

*重要：本版 GAR 是唯讀參考介面。 索引不會直接修改樂譜，也不會呼叫 GSTE 重算、Joint 或輸出器；不應將其視為已完成的半自動改譜功能。需要實際改譜時，請另用熟悉的樂譜編輯工具。GAR 所列為簡化的靜態指法參考，尚未經 GSTE Joint 完整驗證，節奏起音模板也不是原譜節奏重建。

初次使用者可先只看 `GSTE_TAB.musicxml` 與 GAR 索引；`debug/` 主要供程式問題追查。團譜雖有四個伴奏欄位，建議從一至兩軌開始，視實際聽感增減。

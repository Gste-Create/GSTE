# GSTE V0.4 — 問題回報指南

感謝協助測試 GSTE 測試版。請描述實際結果，不需要自行判斷負責的程式模組、演算法或錯誤分類。

## 建議提供的資訊

- GSTE 版本與輸入模式：鋼琴、主旋律＋自動伴奏、主旋律＋無伴奏或團譜。
- 問題簡述，以及是否產生輸出。
- 優先提供 `PRIVACY_SAFE_DEBUG_REPORT.md`。
- 如有 `ERROR_REPORT.md`，檢查內容後提供。
- 其他診斷檔僅在確認可以分享後提供。
- 已知的問題位置，例如小節編號。

若精簡診斷已足夠，不必提交原始樂譜或完整 `debug/` 資料夾。

## 兩種診斷輸出

**隱私安全除錯報告：**採白名單欄位，包含版本、狀態、階段與診斷、工程健康計數、候選數、診斷旗標與區域，以及匿名化分析區段識別。排除曲名、來源檔名與路徑、音高、和弦、音符與節奏序列、歌詞、聲部與軌道名稱、原始事件與區段識別、音樂候選內容及參數值。

**完整工程診斷：**保留於 `debug/` 與處理流程輸出，供本機深入除錯。可能包含音樂內容、路徑、候選與參數，不應視為可直接公開或提供第三方人工智慧的資料。

涉及商業合作、保密協議、內部或未公開作品時，請先提供隱私安全報告。精簡報告也須遵守合約、組織、雇主與客戶的資料政策。

## 描述實際現象

例如轉換中途停止、沒有輸出、小節節奏錯誤、旋律音高改變、六線譜指法異常、出現譜面沒有的播放聲音、無法啟動或介面無回應。

## 是否需要樂譜？

不一定。先提供錯誤報告與精簡診斷。部分問題需比較原始 MusicXML、內部處理與最終輸出，才能找出首次差異；維護者可能再請你提供輸入 MusicXML、轉換後的樂譜或其他相關輸出。

只提交有權分享的樂譜。若可重現問題，優先使用公共領域或具適當授權的測試材料。

## 人工智慧輔助除錯

GSTE 正常轉換不需要人工智慧，也不會自動將輸入 MusicXML 提交給人工智慧。程式開發與除錯可能使用人工智慧。

提交樂譜本身不代表同意人工智慧分析。回報包含樂譜時，請選擇：

- [ ] 同意將本次提交的樂譜用於人工智慧輔助除錯。
- [ ] 不同意將本次提交的樂譜用於人工智慧輔助除錯。

未明確同意時，提交的樂譜不得用於人工智慧輔助分析。不同意不影響正常使用或問題回報。仍可提供精簡報告、已檢查的錯誤報告、可分享的其他診斷、描述、截圖及願意提供的資訊。完整政策請參閱發行包內的 `AI_POLICY.md`。

## 著作權與隱私

不要提交無權分享的樂譜、密碼、應用程式介面金鑰、驗證憑證、敏感個資、公司機密，或不希望向維護者或公眾揭露的內容。

## V0.4 回報細節

記錄伴奏模式與團譜各欄角色、順序；提供原譜小節標籤及選段序號。讀譜畫面或播放異常時，附上讀譜軟體版本。

`HUMAN_REVIEW_REPORT.md` 與 `MEASURE_LOCATION_GUIDE.md` 可協助定位，但不是隱私摘要。`ERROR_REPORT.md` 可能包含來源路徑、錯誤文字及位置。附檔前請閱讀[分享指南](SHARING_GUIDE.md)。

請說明輸入了什麼、發生什麼，以及實際得到什麼；問題定位及錯誤分類交由除錯流程處理。

## V0.4 beta：歡迎音樂性與介面回饋

除了程式錯誤，也歡迎回報：(1) 哪一小節／哪條來源軌保留不足；(2) 希望保留的低音、和弦色彩或節奏；(3) GAR 哪些候選不直覺；(4) 期待如何手動修改。建議提供版本、輸入模式、伴奏軌數、問題小節、實際結果與預期結果；可附截圖或有權分享的短樂譜片段。**不必提供完整 debug 包或未授權的作品**。回饋不代表一定會納入下一版本。

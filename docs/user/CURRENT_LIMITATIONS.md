# GSTE Beta V0.1 — 目前限制

GSTE Beta V0.1 的公開重點是驗證兩條輸入路徑、核心正確性、穩定性、可除錯性與基本指彈吉他編曲流程。

目前限制包括：

- 主要輸入格式為 MusicXML（`.musicxml` / `.xml`）。
- GUI 公開 **雙手鋼琴**與**單旋律**兩條路徑。
- 團譜入口保留，但 Beta V0.1 暫不開放。
- 雙手鋼琴 GUI 目前以主旋律／右手與左手／伴奏兩份 MusicXML 作為輸入。
- 單旋律路徑使用目前固定的 Auto 編曲流程；一般使用者不需要手動設定內部工程參數。
- 自動編曲仍可能出現音樂性、節奏、和聲、伴奏密度、把位、指法或排版不理想的情況。
- 成功輸出不代表作品已達可直接公開或演出的品質；仍需人工確認。
- Beta 的 `debug/` 會保留較完整的工程診斷資料，主要用於問題回報。

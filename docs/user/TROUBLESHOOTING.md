# GSTE Beta V0.1 — 常見問題

## 程式無法啟動

1. 請從正式 Beta 安裝結果啟動 GSTE。
2. 嘗試從 Windows 開始功能表啟動 GSTE。
3. 若仍無法啟動，記錄 Windows 版本、安裝方式與發生情況後回報。

## 按下轉換後失敗

1. 確認輸入檔為 `.musicxml` 或 `.xml`。
2. 雙手譜模式需同時選擇主旋律／右手與左手／伴奏檔。
3. 單旋律模式只需選擇主旋律檔。
4. 查看輸出資料夾是否產生 `ERROR_REPORT.md`。
5. 回報時優先提供 `PRIVACY_SAFE_DEBUG_REPORT.md` 與問題描述；若有 `ERROR_REPORT.md` 也一併提供。完整 `debug/` 可能含較詳細資訊，僅在確認可分享且維護者確實需要時提供。

## 轉換成功但樂譜結果不理想

這不一定代表程式崩潰。請記錄：

- 哪一小節或區段有問題
- 問題屬於旋律、節奏、和聲、伴奏、指法、把位或排版
- 若可以分享，可依 [`ISSUE_REPORT_GUIDE.md`](ISSUE_REPORT_GUIDE.md) 提供相關檔案

若要提交原始樂譜，請確認你有權分享；是否同意將提交的樂譜用於 AI 輔助除錯，請依問題回報指南另外選擇。

## GUI 語言

繁體中文與 English 只改變 GUI 顯示文字，不應改變轉換結果。若切換語言後影響轉換行為，請視為 Beta bug 回報。

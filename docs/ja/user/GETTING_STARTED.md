# GSTE V0.4 beta — インストールと操作

## インストールと起動

1. リリースのダウンロードページから GSTE V0.4 beta の EXE インストーラーをダウンロードします。
2. ダウンロードしたインストーラーを実行し、画面の指示に従ってインストールを完了します。
3. インストール後に作成されたアプリケーションのショートカットから GSTE を起動します。

Python を別途インストールする必要はありません。ダウンロードした EXE はインストーラーです。インストールを完了してから使用してください。

## 入力ファイルの準備

非圧縮の `.musicxml` または `.xml` を使用し、楽譜ソフトで開けることを事前に確認してください。圧縮された `.mxl` は非圧縮 MusicXML として保存し直してください。本版の GUI は MIDI 入力の完全な変換には対応していません。

ピアノとアンサンブルのモードでは、入力ファイルを分けて用意し、開始時刻、小節位置、拍子記号が一致していることを確認してください。

## モードの選択

1. **主旋律のみ：** 旋律ファイルを1つ選び、自動伴奏を生成するか、伴奏を付けないかを選択します。旋律がピアノの左右の手にまたがる場合は、独立した旋律ファイルに整理してください。伴奏なしを選んでも、両手にまたがるすべての旋律を自動認識するわけではありません。
2. **両手ピアノ：** 主旋律／右手と左手／伴奏のファイルを別々に指定します。伴奏は原曲から分析されます。すべての伴奏の発音開始を強制的に保持する GUI オプションはありません。
3. **アンサンブル（実験）：** 主旋律と1～4つの伴奏ファイルを指定します。各伴奏に GUITAR（ギター）または BASS（ベース）を割り当てます。複数のギタートラックには同じ役割を使え、リードとリズムを分ける必要はありません。前に配置された伴奏欄ほど固定の統合重みが高くなります。ただし、これは音符の保持率ではなく、前のトラックの全音符が保持される保証でもありません。[入力モード](INPUT_MODES.md)を参照してください。

## 変換と確認

GUI の言語と出力フォルダーを選び、「変換開始」を押します。変換ごとに結果フォルダーが作成されます。成功後は「完成した楽譜を開く」または「出力フォルダーを開く」を利用できます。

まず旋律、リズム、譜面を確認し、その後、人による確認用レポートで運指と伴奏を照合してください。失敗した場合は `ERROR_REPORT.md` を読み、[出力ガイド](OUTPUT_GUIDE.md)を参照してください。

言語切り替えで変わるのは GUI の表示文言のみです。新たに追加された外側の人間向けレポートは現在主に中国語で、技術レポートには英語のフィールド名が残ります。

## V0.4 beta：GAR 編曲リファレンス索引（実験機能）

GSTE の変換後に編曲索引を開き、確認したい小節を選びます。統合された「コード運指／伴奏編成」索引では、主旋律のポジション付近や未使用の弦の候補を6線 TAB の図とともに確認できます。現在の伴奏で使える弦・ポジションや、コードを変更した場合に使える弦・ポジションの参考になります。主旋律の重音運指の提案も表示されます。

*重要：* 本版の GAR は閲覧専用の参考画面です。索引は楽譜を直接変更せず、GSTE の再計算、Joint、エクスポーターも呼び出しません。完成した半自動楽譜編集機能とみなさないでください。実際の編集には使い慣れた楽譜編集ソフトを使用してください。GAR の候補は簡略化された静的な運指参考情報で、GSTE Joint による完全な検証は行われていません。リズムの発音開始テンプレートも原譜のリズムを再構成したものではありません。

初めて使う場合は、まず `GSTE_TAB.musicxml` と GAR 索引を確認してください。`debug/` は主にプログラムの問題調査用です。アンサンブルには伴奏欄が4つありますが、まず1～2トラックから試し、聴感に応じて調整することを推奨します。

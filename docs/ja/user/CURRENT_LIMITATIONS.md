# GSTE V0.4 — 現在の制限事項

- **入力：** GUI は非圧縮 MusicXML を使用し、MIDI 入力の完全な変換には対応していません。複数トラックは、時間を揃えた個別ファイルを用意する必要があります。
- **アンサンブル譜：** 実験モードではギター／ベースの伴奏欄を最大4つ使用できます。アンサンブル用ピアノの選択肢は非表示です。複数トラックの統合品質には、さらに多くの楽曲での検証が必要で、伴奏構成や原曲素材によって結果が異なります。
- **ピアノ原曲：** 原曲音の制約や小節単位のオクターブ移動は、すべての発音開始や持続音の保持を保証しません。オクターブ選択は運指の全体最適化には至っていません。
- **リズムとパターン：** 変則拍子、シンコペーション、弱起、長周期のフレーズ、分析区間をまたぐフレーズを完全に理解・保持できるとは限りません。
- **調性と和声：** 関係長調と短調の判定が近くなる場合があります。局所的な転調、終止形、和声推論の全体的な最適化は未完了です。
- **音楽品質：** 一部の素材が省略される場合があります。伴奏密度、運指、ポジション、接続については、試聴と実演による確認が必要です。
- **言語：** GUI は繁体字中国語、英語、日本語に対応しています。レポートの概要は GUI の言語に応じて表示されますが、元の技術診断には英語のコードや未翻訳部分が残る場合があります。

変換結果は楽譜ソフトで再生し、人による演奏でも確認してください。

## V0.4 beta／GAR の追加制限

- GAR 編曲索引は現在**閲覧専用**です。運指の直接適用、部分的な再計算、完全な記譜編集を行える完成済みエディターではありません。
- 運指と伴奏テンプレートは参考情報であり、GSTE Joint による完全な検証を受けていません。演奏可能性、リズム、音楽性は手動で確認してください。
- アンサンブルは伴奏欄を最大4つ使用できますが、まず1～2トラックから試すことを推奨します。2トラックでも音楽情報が大幅に圧縮される場合があります。
- 本版は、自動編曲アルゴリズム、音楽性、デモ品質が V0.3 より全面的に向上したと主張するものではありません。

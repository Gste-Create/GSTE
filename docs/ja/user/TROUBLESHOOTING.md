# GSTE V0.4 — トラブルシューティング

## インストールまたは起動の問題

GSTE V0.4 の EXE インストーラーをダウンロードし、インストールを完了したことを確認してください。インストール後のショートカットから起動してください。問題が続く場合は、Windows のバージョン、GSTE のバージョン、インストール中か起動中か、エラーメッセージやスクリーンショットを記録してください。

## 変換の失敗

`.musicxml`／`.xml` 形式、必要な入力、出力先を確認してください。ピアノには左右の手の2ファイルが必要です。アンサンブルには主旋律と少なくとも1つの伴奏が必要で、全トラックの時間軸が一致していることを確認してください。現在、`.mxl` および MIDI 形式には対応していません。

`ERROR_REPORT.md` で原因と失敗段階を確認してください。`NO_VALID_GLOBAL_TRANSFORM` は必ずしも音域超過を意味しません。アンサンブルの変換が失敗した場合は、選択した役割、入力ファイル、レポート内のエラーメッセージも記録してください。調査のため、今回のレポートとバージョン情報を保存してください。

## 変換成功後の譜面異常

まず最上位の `GSTE_TAB.musicxml` を確認してください。`MEASURE_LOCATION_GUIDE.md` で原譜の小節ラベルと選択範囲の通し番号を記録し、旋律、伴奏、リズム、運指の相違点を示してください。楽譜ソフトに問題がある場合はそのバージョンを知らせ、XML の音符内容の問題と画面表示の問題を区別してください。

位置が欠落していたり `NOT_AVAILABLE` と表示されていたりする場合は、根拠が不足していることを示し、正しさが確認されたことにはなりません。[不具合報告ガイド](ISSUE_REPORT_GUIDE.md)を参照してください。

## GAR が見つからない／変更を適用できない

GAR 索引には、GSTE V0.4 で変換した結果に含まれる `GSTE_EDITOR_CONTEXT` が必要です。V0.3 で変換した結果にはこのファイルが含まれません。
GAR 索引は現在閲覧専用です。そのため、コードを変更しても索引ペインのみが変化し、主旋律の重音位置も索引ペイン内で提案されるだけです。

# GSTE V0.4 — ファイル共有ガイド

通常の変換では、楽譜が AI サービスに自動アップロードされることはありません。公開の不具合報告に添付したファイルも公開されます。音楽内容を公開したくない場合は、出力 ZIP 全体ではなく、共有可能な問題説明と許可リスト方式の概要を先に提出してください。

| ファイル | 推奨事項 |
|---|---|
| `PRIVACY_SAFE_DEBUG_REPORT.md` | 優先して提出しますが、事前に内容を確認してください。 |
| `EVENT_LIFECYCLE_TRACE.md` | 簡略化されたライフサイクル情報。共有範囲に適合することを確認してから提出してください。 |
| `CONVERSION_REPORT.md`／`ERROR_REPORT.md` | 事前に確認してください。パス、位置、原曲由来の文字列が含まれる場合があります。 |
| `HUMAN_REVIEW_REPORT.md`／`MEASURE_LOCATION_GUIDE.md` | 位置や根拠への参照が含まれ、プライバシー保護済みの概要ではありません。 |
| 原譜、最終譜、スクリーンショット、`debug/`、原曲音監査 | 音高、リズム、コード、原曲識別、完全な音楽内容が漏れる可能性があります。 |

楽譜を提出しても、第三者の AI による分析への同意を意味しません。[不具合報告ガイド](ISSUE_REPORT_GUIDE.md)に従って明示的に選択してください。明示的な同意がない場合、保守担当者は提出された楽譜を AI 支援分析に使用してはいけません。簡易レポートは技術的な問題の初期診断に役立ちますが、音楽品質の判断には不十分な場合があります。

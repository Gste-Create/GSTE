# GAR 編曲リファレンス — V0.4 beta（実験的機能）

## 目的
GSTE は MusicXML を、確認用のフィンガースタイルギターの五線譜と TAB 譜に変換します。GAR は、押弦ポジション、コードの運指、伴奏配置の参考候補を提示し、原曲のスタイル、聴感、演奏技術に応じて、ユーザー自身が編曲方法を判断できるよう支援します。

GAR は編曲の参考ツールであり、MuseScore などの楽譜編集ソフトの代替ではありません。

## 使い方
1. GSTE V0.4 beta で MusicXML を変換し、出力された `GSTE_TAB.musicxml` を確認します。
2. GAR を開き、確認したい変換結果を選択します。
   - **直前の変換結果**：そのまま GAR を開くと、今回変換した楽譜を確認できます。
   - **過去の変換結果**：GAR で以前の変換結果に含まれる `GSTE_EDITOR_CONTEXT` ファイルを選択すると、その楽譜を読み込んで確認できます。過去の結果を確認するために、元の楽譜を再変換する必要はありません。
3. 確認したい小節を選択します。GAR には主に現在選択中の小節が表示されます。
4. TAB 譜上の主旋律の音符をクリックすると、対応する重音の候補を確認できます。
5. 統合された「コード運指／伴奏配置リファレンス」で、主旋律のポジション付近にある未使用弦を活用した候補と、6 線 TAB の図を確認します。
6. 原曲のスタイル、実際の響き、演奏可能性を考慮して候補を評価します。楽譜を実際に修正する場合は、別の楽譜編集ソフトを使用してください。

## 重要な制限事項
**GAR V0.4 beta は閲覧専用の編曲リファレンスです。** GAR で候補を確認・選択しても、その内容は GSTE に書き戻されず、Joint 編曲処理、再計算、修正版楽譜の出力も行われません。

候補は簡略化された静的な参考情報です。すべての運指が実際に演奏可能であることや、リズムが原譜と完全に一致することは保証されません。必要に応じてユーザー自身で確認・調整してください。

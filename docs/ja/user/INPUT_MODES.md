# GSTE V0.4 — 入力モードと役割

| モード | 必要なファイル | 伴奏方法 |
|---|---|---|
| 主旋律＋自動伴奏 | 主旋律ファイル1つ | 伴奏を生成 |
| 主旋律＋伴奏なし | 主旋律ファイル1つ | 伴奏を追加しない |
| ピアノ | 主旋律／右手と左手／伴奏 | 原曲分析 |
| アンサンブル | 主旋律と1～4つの伴奏トラック | 役割分析と統合 |

## アンサンブルのギター

GUITAR はギター伴奏の役割で、複数のギタートラックを同時に入力できます。ストロークやアルペジオなどのパターンは音楽内容から分析され、リード／リズムギターという名称では決まりません。主旋律は引き続き別ファイルで入力する必要があります。

各トラックには楽器の役割に応じて固定の Harmony/Bass/Texture/Rhythm 重みが適用され、その後、伴奏分析と統合が行われます。重みは音符の保持率を意味せず、トラック全体の保持を保証しません。原曲の識別ではトラックを区別しますが、統合時に競合する素材が省略される場合があります。GUITAR を指定しても、すべてのストローク、アルペジオ、装飾的なフレーズが原形のまま保持されるわけではありません。

## ピアノの原曲音ポリシー

ピアノの既定値は `SOURCE_AT_ATTACK` です。伴奏の発音開始候補は、その時点の原曲音に制約され、同一の実小節では共通のオクターブ移動が使われます。発音開始や音符が省略されたり、持続音が短くなったりする場合があります。オクターブ選択は音域に基づいており、運指の全体最適化ではありません。

現在、原曲伴奏のすべての発音開始で少なくとも1音を必ず保持する仕組みや、フレーズ全体・拍群単位のオクターブ移動はありません。アンサンブルの各トラックに同等の原曲保持保証があると解釈しないでください。

## V0.4 beta アンサンブルの推奨事項

アンサンブル機能は引き続き実験段階であり、音楽性の保持は人による確認が必要です。

アンサンブル GUI には最大4つの GUITAR/BASS 伴奏トラックを入力できますが、**まず1～2トラックから始めることを推奨します**。主旋律、重要な低音、最も重要な和声／リズム声部を優先してください。2トラックでも、1本のギターの音域、同時発音数、運指の制約によって音楽情報が大幅に圧縮される場合があります。4トラックは実験的な入力上限であり、**4声部すべての完全な保持を約束するものではありません**。結果が不十分な場合は、単純にトラックを増やすのではなく、原曲のトラック分離を調整し、個別の変換結果を比較してください。

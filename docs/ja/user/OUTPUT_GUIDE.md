# GSTE V0.4 — 出力ガイド

まず最上位のレポートを読み、詳細な診断が必要な場合に `debug/` を確認してください。変換が早期に停止した場合、一部のファイルが存在しないことがあります。

| ファイル | 用途 |
|---|---|
| `GSTE_TAB.musicxml` | 成功時の最終的な五線譜と TAB。再生と人による確認にはこのファイルを使用します。 |
| `CONVERSION_REPORT.md` | 完了の概要であり、音楽品質の認証ではありません。 |
| `ERROR_REPORT.md` | 失敗段階、エラー、取得できた位置と根拠。 |
| `HUMAN_REVIEW_REPORT.md` | 記録された運指、要確認事項、保持されなかった優先イベント。注意表示は確定したエラーとは限りません。 |
| `MEASURE_LOCATION_GUIDE.md` | 原譜の小節ラベルと選択範囲内の通し番号の対応。 |
| `PRIVACY_SAFE_DEBUG_REPORT.md` | 許可リスト方式の診断概要。不具合報告の添付として優先的に推奨します。 |
| `EVENT_LIFECYCLE_TRACE.md` | 簡略化されたイベントのライフサイクル診断。共有前に確認が必要です。 |
| `debug/` | 完全な診断と中間出力。音楽、パス、原曲情報が含まれる場合があります。 |

成功・失敗のいずれでも、人による確認レポートと小節位置レポートが生成される場合があります。根拠がない場合はその旨が示されます。中間ファイルの `04_PRE_FINAL_REVIEW_TAB.musicxml` と `05_TAB.musicxml` は最上位の最終譜の代わりにはなりません。`debug/ARTIFACT_TRACE.json` には書き込み、再書き込み、コピー元が記録されます。

## 位置と状態

原譜の小節ラベルは入力 XML に従います。選択範囲の通し番号は今回の入力内の小節順序を表します。原曲側で番号が変更されている場合、レポートから元の全曲の番号を復元することはできません。拍位置の単位は各診断の定義に従い、欠落した情報は推測しません。圧縮ファイルや小節ラベルがない場合、対応関係が不完全になることがあります。

`PASS` は該当検査に合格したことだけを示します。`REVIEW` は確認が必要、`FAIL` は該当検査の失敗、`NOT_AVAILABLE` または `UNAVAILABLE` は根拠が不足していることを示します。優先イベントが0件でも旋律の完全性が証明されたわけではありません。[レポートの読み方](REPORT_READING_GUIDE.md)を参照してください。

## V0.4 beta の出力と索引

`GSTE_TAB.musicxml` は引き続き主要な楽譜出力です。GAR 索引は参考画面にすぎず、**人が編集した新しい楽譜を生成しません**。GAR に表示された候補が出力ファイルに書き込まれたと考えないでください。既存の V0.3 デモはすべて V0.3 による自動変換結果で、GAR による再編曲は行われていません。

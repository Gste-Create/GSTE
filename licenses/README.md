# GSTE Beta V0.2 — 上游授權文件 / Upstream license documents

## 繁體中文

本資料夾保留第三方授權原文，不改寫法律條文或把自行翻譯當作上游正式授權。完整元件盤點與尚待核實事項見 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。來源網址、取得日期與原文雜湊見 SOURCES.json。

| 文件 | 用途 |
|---|---|
| PYTHON-3.11.9-LICENSE.txt | Python 3.11.9 授權原文。 |
| PYTHON-3.11.9-INCORPORATED-SOFTWARE.rst | Python 內含其他軟體的通知。 |
| OPENSSL-3.0.13-LICENSE.txt | OpenSSL 3.0.13 授權原文。 |
| TK-license.terms | 所附 Tk 授權原文。 |
| NUITKA-LICENSE.txt | 已取得的 Nuitka 原文；尚未確認匹配實際 build 版本。 |

僅將這些文件上傳 GitHub，不會把它們加入既有 EXE、安裝檔或 Portable；實際發布包仍需核對版本並附帶適用通知。

## English

This folder preserves upstream license originals. Legal texts are not rewritten, and informal translations are not substituted for the official terms. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for component inventory and outstanding checks. SOURCES.json records source URLs, retrieval dates and original hashes.

| File | Purpose |
|---|---|
| PYTHON-3.11.9-LICENSE.txt | Original Python 3.11.9 license. |
| PYTHON-3.11.9-INCORPORATED-SOFTWARE.rst | Notices for other software incorporated into Python. |
| OPENSSL-3.0.13-LICENSE.txt | Original OpenSSL 3.0.13 license. |
| TK-license.terms | Supplied original Tk license. |
| NUITKA-LICENSE.txt | Retrieved Nuitka text; not verified against the actual build version. |

Uploading these documents to GitHub does not insert them into an existing EXE, installer or Portable package. Actual release packages still need version verification and accompanying applicable notices.

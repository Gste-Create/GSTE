# Official third-party license sources

This directory collects license material and authoritative upstream references for third-party runtime components used by GSTE Beta V0.1.

## Python 3.11.x runtime

Official license and incorporated-software acknowledgements:
https://docs.python.org/3.11/license.html

The Python Software Foundation license permits binary redistribution subject to its terms, including retention of the applicable PSF license agreement and copyright notice. Python also incorporates software covered by additional notices; use the official page above as the authoritative reference for the Python 3.11 distribution.

## Tcl/Tk 8.6.x

Official licensing terms:
https://www.tcl-lang.org/software/tcltk/license.html

The license text shipped with the packaged Tk runtime is retained as `TCL_TK_LICENSE.txt` in this directory.

## OpenSSL 3.x

Official licensing information:
https://openssl-library.org/source/license/index.html

OpenSSL 3.0 and later are distributed under Apache License 2.0. A copy is retained as `APACHE-2.0.txt`.

## Microsoft Visual C++ Runtime

Microsoft Visual C++ runtime files are redistributed under the applicable Microsoft Visual Studio / Visual C++ Redistributable terms. The Microsoft runtime is not licensed under the GSTE Beta license.

This index does not replace any notice or license that must accompany a specific third-party binary. If the packaged runtime changes, review `THIRD_PARTY_NOTICES.md` and this directory again before release.
